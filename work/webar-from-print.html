Case · WebAR

WebAR from a printed page

Markers for a menu, a plan, a sofa, a card, a vehicle, and a box. Unity 2022.3. The files are on this site.

Open the markers
  1. Problem

    A book, a menu, a pack, or a card is already in someone’s hand. Asking them to install an app before they see the extra layer is a hard sell.

  2. Build

    A reusable WebAR stack in Unity 2022.3, triggered from image markers. The public set covers a restaurant menu, a floorplan, animal tattoos, a retail sofa, vehicle advertising, a business card, and an on-pack clip. A kids’ board book, Wild Wonders, is the AR-books example.

  3. Result

    The markers and the packaging clip can be downloaded from the WebAR page. That page is the working link. If a hosted experience URL goes stale, the note on that page is to re-host it — these case notes point at the files on this site, which are the ones that open.

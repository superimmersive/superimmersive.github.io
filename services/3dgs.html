3DGS capture and processing

Pipeline ready; requires 360 drone.

A commissionable service that captures real spaces as photorealistic, navigable 3D environments using 3D Gaussian Splatting. The output runs in a web browser — the viewer moves through the space smoothly, unlike older virtual tours that jump between fixed photo points.

Captures also feed Super Immersive Homes as the real-building walkthrough layer.

What we already have

  • Small-object capture on iPhone 16 Pro.
  • Processing in Unity, Blender, WebAR, and React Three Fiber.
  • Cleanup, lighting correction, and branded presentation — the same finishing delivered weekly to Fuzzy Logic Studio (UK).

# Client work stills

Drop photos, GIFs, or videos in the client folder. Any filename works — they do not have to be `01.jpg`. Hover (or tap on a phone) opens a strip of three; click-drag or scroll to see the rest. Videos stay paused in the strip and only play in the large panel; closing the panel stops them. GIFs show in the strip as stills that animate. Missing folders still show `placeholder.jpg` (NDA / can’t show images). No HTML edit needed.

```
assets/clients/<slug>/any-name.jpg
assets/clients/<slug>/any-name.png
assets/clients/<slug>/any-name.gif
assets/clients/<slug>/any-name.mp4
```

`.webp`, `.jpeg`, `.webm`, and `.mov` also work. Numbered files (`01`, `02`…) sort first.

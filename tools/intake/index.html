Product intake

Add a USDZ to the AR app. One publish commits the model, the Ask text, and the examples list on the live site.

How to publish and test

What publish writes

  • models/<id>.usdz — the file the app downloads, at https://superimmersive.io/models/<id>.usdz.
  • models/catalog.json — only when “Examples list” is ticked, or when that tick is cleared on an id that was listed. Existing example models are locked.
  • ar/models/<id>.json — the same Ask fields the app already reads for ?model=<id>, plus placement and the download URL.
  • models/thumbs/<id>.jpg — optional. The catalog has no thumbnail field, so the app does not show it.

Placement is floor or wall. Animation mode is written only as scrub; a loop is the default and the field is left off, matching Biplane, Robot, and Axel Flux Motor. The share link is https://superimmersive.io/ar?model=<id>.

Local Experience

  1. Wait until the USDZ URL downloads in Safari. Pages often takes a minute or two after the commit.
  2. On the iPhone, turn on Developer Mode, then Settings → Developer → Local Experiences → Register Local Experience.
  3. URL prefix https://superimmersive.io/ar. Bundle ID io.superimmersive.ar.Clip (team U5DGDWXQCP in the site association file).
  4. Open the share link in Safari. The clip should place the model on the surface you chose, loop or scrub as ticked, and answer from the FAQ.

A clip already associated in App Store Connect can open the same link without a Local Experience. The association file is unchanged.
